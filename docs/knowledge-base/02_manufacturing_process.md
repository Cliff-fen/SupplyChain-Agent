# 制造供应链分析流程（演示版）

> 文档类型：流程 | 数据性质：合成演示数据 | 版本：2026-08-19

本文为制造流程示例说明，参考公开的 [NIST Manufacturing](https://www.nist.gov/manufacturing) 术语和 [ASCM SCOR](https://www.ascm.org/standards/scor-ds/) 流程分层，不包含受限企业 SOP。

## 从采购到生产

1. 采购订单引用供应商和计划交付日期。
2. 物料到货后更新 `delivered_date` 与订单状态。
3. 生产工单记录工厂、产品线、计划数量和完工数量。
4. 质量检验关联工单，记录检验数量和通过数量。
5. 库存快照按物料、工厂、日期保存，用于识别缺料风险。

## 从销售到交付

销售订单记录承诺日期和累计交付数量；交付计划记录计划日期与实际日期。承诺日期已过、实际日期为空或交付数量不足时，分析结果应标记为 at-risk。

## 例外处理

发现迟交、缺料、低合格率或订单延期时，报告必须包含影响范围、计算口径、数据源表和建议的下一步核查动作。流程文档只提供分析依据，不替代现场审批。
