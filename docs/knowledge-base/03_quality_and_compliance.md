# 质量与数据使用规范（演示版）

> 文档类型：制度规范 | 数据性质：合成演示数据 | 版本：2026-08-19

本文是质量管理测试示例，相关质量管理概念可参阅公开的 [ISO 9001 介绍](https://www.iso.org/iso-9001-quality-management.html)。正式生产使用前应由质量负责人审核。

## 数据可信度

- 演示源库中的供应商、订单、库存和质量记录均为合成数据，代码和文档中不得称为客户真实数据。
- 每个指标必须能回溯到表、字段、筛选条件和文档版本。
- 缺失日期、零分母和重复快照必须显式处理，不得静默填零。

## 只读与权限

分析账号只能执行单条 `SELECT` 或 `WITH` 查询；禁止写入、DDL、系统表访问和跨租户资源访问。凭据由平台加密保存，日志中不得出现密码。

## 异常阈值

生产达成率低于 90%、库存安全度低于 0.5、一次合格率低于 98% 或订单逾期即进入人工复核队列。阈值是演示默认值，可在组织级知识库中覆盖。
