# 试运行已知限制

## 本次已验证

- API/Worker 使用独立健康检查，API 不再在启动时执行 Alembic。
- `trial` 覆盖文件要求非开发 JWT、凭据加密密钥和对象存储凭据，并把迁移保留为显式步骤。
- 摄取、Schema 同步、大屏刷新、PDF 导出和分析运行的超时状态会由看门狗处理。摄取在可重试范围内重新排队，其余外部操作明确失败，避免不可见的重复写入。
- 运营总览、项目管理、企业管理、大屏配置、分析会话、数据源、知识库、报告中心、组织与审计及系统状态均为独立领域路由。运营总览使用独立加载状态、即时筛选和按需加载图表。

## 尚未作为本轮发布承诺的事项

- 试运行版本仅保留正式业务路由，不包含历史控制台实现。
- CI 已覆盖单测、Ruff、构建、Compose 配置、Helm 模板与依赖扫描。真实模型分析需要在已配置的内网试运行环境进行人工验收，CI 只验证未配置模型时的 fail-closed 行为。
- 本试运行版不包含完整 OIDC、Kubernetes、跨地域容灾、零停机迁移或生产 SLA。
- 数据库和 MinIO 备份命令必须由目标环境的运维账号执行。发布前需要演练一次一致性恢复。
