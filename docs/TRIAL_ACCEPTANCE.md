## 观察到的恢复行为

摄取、Schema 同步、大屏刷新、PDF 导出和分析运行均保存开始/结束时间、尝试次数与错误摘要。看门狗会重新入队仍可安全重试的摄取任务；其余外部副作用任务转为失败并保留 Trace ID、失败原因及相应的重试入口，避免界面永久停留在“处理中”。系统状态汇总所有上述任务的失败数量；数据源详情可重新同步或取消排队/运行中的同步任务。知识库创建和上传在异步请求后使用已保存的表单引用，避免 React 事件失效造成列表不刷新。
