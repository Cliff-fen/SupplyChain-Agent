# 试运行回滚手册

1. 记录当前镜像标签并停止写入：`docker compose ... stop api worker beat`。
2. 恢复发布前 PostgreSQL 备份和对应的 MinIO bucket 备份；两者必须来自同一时间点。
3. 将 `SUPPLYMIND_RELEASE_TAG` 改为上一已验收标签，显式运行该版本的 `migrate`。仅允许向前兼容的迁移上线；若存在破坏性迁移，必须提供对应恢复脚本后才可发布。
4. 启动服务并验证 live/ready、登录、数据源只读查询、一次真实分析和 PDF 下载。
5. 在审计记录中登记回滚时间、操作者、标签、备份时间点和验证结果。

已知限制：本版本不提供跨地域容灾、零停机迁移、OIDC 完整接入或生产 SLA；模型可用性仍依赖内网已批准的兼容服务。
