# 可核查的验收方法

验收对象为当前 LangGraph、PostgreSQL Checkpointer、Celery/Outbox、MCP 和前端的真实实现。
不以模板答案、模拟模型输出或前端自造进度替代真实流程。每次部署单独保存证据；历史通过不能自动代表新版本通过。

## 证据最小集合

每条分析记录保存 `run_id`、`checkpoint_thread_id`、HTTP 请求 Trace ID 和 Worker 图执行 Trace ID。
请求和异步 Worker 可产生不同 Trace ID；重试可产生多个 Worker Trace，必须通过运行 ID 关联，不能只保存一个截图。
保存事件序号、步骤、执行 SQL、数据库行、图表字段、引用块 ID、文档版本、源文件 SHA-256、报告导出记录及对象校验和。
真实业务数据、令牌、密钥和数据库备份只进入私有证据目录，不提交版本库。

## 执行顺序

1. 解析开发和试运行 Compose；启动核心服务，等待实际健康检查通过。分别访问 live/ready、文档、前端、MinIO、Prometheus、Grafana 和 MCP。
2. 检查单一 Alembic head；在独立数据库测试空库升级和迁移往返。在独立数据库恢复备份，使用旧镜像读取已保存检查点，禁止覆盖在线库演练。
3. 真实调用 Chat、Embedding、Rerank；分别撤去必要配置或使服务不可达，核对显式错误、Trace ID 和后续恢复。Rerank 未配置时原流程允许 LLM 重排，不能将这种回退误报为专用重排服务成功。
4. 实测 data、knowledge、hybrid、unsupported 路由。混合任务核对两个子任务并行、一次合并；逐项记录 Handoff、SQL Guard、RAG、Verifier 和审批事件。
5. 查询 PostgreSQL/MySQL 角色权限，并在数据库层直接尝试零行 UPDATE，确认账号本身无写权。另测 SQL AST、白名单、LIMIT、超时和超时后恢复。
6. 上传真实文档、替换版本、回退版本，确认子块实际有向量。同组织两个知识库上传相同内容时，必须在各自知识库生成独立文档；同库重复上传保持幂等。
7. 比较实际数据库查询行、图表字段和报告结果；通过引用块定位文档版本、原文件与哈希。检索失败必须明确降级或失败，不得生成虚假引用。
8. 切断 SSE 后用 Last-Event-ID 重连，核对无重复、无缺号及终态。强制结束一个正在执行的 Worker 子进程，核对恢复使用原检查点、已完成工具不重复执行、报告不重复创建。
9. 暂停 Redis、模型、MCP、业务数据库和对象存储后恢复。每次仅中断验收部署中的目标服务，使用 finally 恢复。检查失败持久化、Outbox 重投、重试上限和用户手动重试。
10. 对等待审批的检查点分别通过和拒绝。先保存审批，再由 Outbox 派发恢复；恢复前重新校验当前角色和资源授权。普通只读问题不默认触发图审批；可显式构造审批边界的恢复夹具，但必须标注测试注入。
11. 生成 Markdown/PDF；从 MinIO 读取实际对象比对 SHA-256，再验证下载鉴权、跨组织拒绝及 PDF 每页实际渲染。导出失败后用正式重试接口恢复。
12. 运行后端测试、规则门禁、前端单测/构建、浏览器测试、Ruff、编译、密钥扫描、依赖扫描、镜像和配置扫描及 SBOM。区分“本地命令通过”和“托管 CI 已通过”。

## 账号和部署约束

演示 PostgreSQL 使用 `supplymind_demo_admin` 初始化和导入，只读分析使用独立的 `supplymind_ro`。
MySQL 初始化脚本完成种子导入后撤销分析账号写权限。示例密码仅用于本地演示。
已有数据卷不会重新执行初始化脚本；升级时须先备份并迁移账号权限，不能通过删卷重建伪装无损升级。
早期 PostgreSQL 将分析账号作为 initdb 引导账号时，该角色不能直接撤销超级权限。
迁移应使用独立维护账号，将旧角色改名并禁用登录，再创建同名的真正只读分析账号；保留原对象和数据。

容器应用以 UID/GID 10001 运行。已有文档和报告卷需由部署管理员迁移所有权，不能扩大为全目录 777。
Helm 的 API 与 Worker 使用同一个持久卷；多副本需要实际提供 ReadWriteMany 的存储类或预建 PVC。
`helm lint/template` 只证明静态配置可渲染，不证明集群已经部署或已具备高可用能力。

## 能力口径

- Verifier 沿用当前仓库的规则式证据检查，不是逐句语义事实核验模型，不能据此承诺零幻觉。
- 固定正反门禁样例验证门禁是否阻止坏版本，不是大规模正确率测试。
- Token 指标含基于字符长度的估算值，不能当作供应商账单。
- SQL、图表和引用可回到实际导入源；合成演示数据必须标注，不能描述为真实客户生产数据。
- 权限隔离验收须覆盖 HTTP、SSE、MCP、A2A、审批、记忆和报告下载，不能只依据菜单隐藏或某一个数据库策略。
- 本地验收不替代实际 OIDC 提供商集成、生产负载测试、渗透测试或 Kubernetes 集群演练。
